# FGBN Bank – Mock Digital Banking Application

A mock digital banking web application built to demonstrate core JavaScript logic, authentication, and real-time data handling using Firebase. This project simulates basic banking operations within a controlled environment and focuses on clean UI and functional workflows.

---

## Live Demo
https://fgbn-bank.vercel.app/

---

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend / Services:** Firebase (Authentication, Firestore)
- **Hosting:** Vercel

---

## Features
- User authentication (sign up & login)
- Dashboard for logged-in users
- Internal transfers between mock bank users
- Real-time data updates using Firebase
- Responsive design for mobile and desktop
- Form validation and basic error handling

---

## Purpose of the Project
This project was built to:
- Strengthen understanding of JavaScript logic and state handling
- Practice integrating Firebase authentication and database services
- Simulate fintech-style workflows in a simplified environment
- Build confidence working with real-time data and user sessions
